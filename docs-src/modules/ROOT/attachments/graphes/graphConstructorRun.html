Graph Constructor — Computational Experiment

Select Add Vertices to place or remove vertices. Drag a vertex to an empty grid cell to move it; Ctrl+Z undoes changes. Select Add Edges, then click two vertices to connect them with a green edge. Select the same pair again to remove the edge or arc. In Directed Graph mode, click a line while Add Edges is active to change its direction. Build a matrix when your graph is ready.
